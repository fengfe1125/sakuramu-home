这是一篇示例手记，用来演示排版。删掉这个文件，或者直接改成你自己的内容。

写法很简单：往 `v2/notes/` 里丢一个 `.md` 文件，开头用 `---` 包一段 front-matter 写标题和日期，然后正文照常写 Markdown。发版时会自动渲染成 HTML 直接写进页面，**访客那边不需要下载任何解析器**。

## 支持哪些写法

常用的都在：**加粗**、*强调*、`行内代码`、[外链](https://sakuramu.edu.kg)，以及列表、引用、代码块和分割线。

- 中英文之间会自动补空格，比如 TokenTracker 和 macOS 这种混排
- 数字也一样，写 365 天不用自己敲空格
- 正文第一段的首字会自动下沉

> 引用长这样。段落之间留空行就会各自成段。

```swift
// 代码块保持原样，不做任何转义之外的处理
public static func isAcceptedBundleID(_ id: String) -> Bool {
    id == bundleIDRoot || id.hasPrefix(bundleIDRoot + ".")
}
```

---

文件名建议用 `日期-标题.md` 的形式，排序按 front-matter 里的 `date` 倒序，最新的在最上面。
